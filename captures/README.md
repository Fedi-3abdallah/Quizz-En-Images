# Captures d'écran

Placer ici les captures prises sur émulateur ou téléphone :

- `question.png` : une question avec image, trois boutons, score en haut à droite et barre de progression
- `bonne-reponse.png` : bonne réponse, score mis à jour
- `mauvaise-reponse.png` : mauvaise réponse, score inchangé
- `ecran-final.png` : écran final avec le score obtenu
